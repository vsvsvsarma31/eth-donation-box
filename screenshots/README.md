# Screenshots

Add screenshots of your deployed dApp here.

Suggested screenshots to include:
1. `01-wallet-connect.png` — MetaMask connect prompt
2. `02-main-ui.png` — Main dApp interface with stats loaded
3. `03-donation-pending.png` — MetaMask transaction confirmation popup
4. `04-donation-confirmed.png` — Success state after donation confirmed
5. `05-etherscan-contract.png` — Contract page on Sepolia Etherscan
6. `06-owner-panel.png` — Owner panel showing withdraw button (if you are the owner)

To take screenshots:
- On Mac: Cmd + Shift + 4, then select area
- On Windows: Win + Shift + S
- In Chrome: F12 → ··· → More tools → Screenshot (Ctrl+Shift+P → "screenshot")

Paste images directly into the `screenshots/` folder and reference them in the README.
