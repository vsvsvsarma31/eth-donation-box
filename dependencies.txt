# ============================================================
# ETH Donation Box — Dependency Reference
# ============================================================
# This project has NO npm/pip dependencies.
# It is a static frontend (HTML + CSS + JS) + a Solidity contract.
# Everything runs in the browser. No build step. No node_modules.
# ============================================================
